# CoWorks — AI Workforce Intelligence (UI scaffold)

This workspace contains a production-ready frontend scaffold for "CoWorks", a premium AI Workforce Intelligence product.

Tech stack:
- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion, GSAP
- Three.js with React Three Fiber
- React Router

Quick start:

Install dependencies:
```
npm install
```

Run dev server:
```
npm run dev
```
Run the watch demo alias:
```
npm run watchdemo
```

Notes:
- Dark mode enabled by default via `class` on `<html>` in `index.html`.
- Use `src/components/ThreeBlob.tsx` as a starting point for Three.js visuals.
- Framer Motion variants live in `src/animations/motion.ts`.
